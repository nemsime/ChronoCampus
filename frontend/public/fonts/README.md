# Locally hosted fonts

- [Bricolage Grotesque](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque): variable upright font, weights 200–800.
- [Inter](https://github.com/google/fonts/tree/main/ofl/inter): variable upright font, weights 100–900.

Downloaded from the official Google Fonts repository on 15 November 2026. The
original SIL Open Font License files are included beside each unmodified font.
The app serves fonts locally with `font-display: swap`; no font service request
is required at runtime. Unsupported scripts use the configured Armenian/system
fallbacks.
